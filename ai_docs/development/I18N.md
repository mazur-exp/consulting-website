# Языки на сайте: где они живут и как добавить ещё один

Сейчас четыре: `ru`, `en`, `id` (Bahasa), `th` (тайский). Английский —
фолбэк для всех.

## Главное, что стоит знать заранее

Перевод сайта — это **четыре независимых слоя**, а не один. Видимый текст
находится инструментом за час; остальные три живут отдельно, у каждого своя
развилка по языку, и каждый молча отдаёт английский, если про него забыть.
Проверять «есть ли на странице буквы нужного алфавита» бесполезно: страница
может быть полностью переведена, а `<title>`, `meta description` и JSON-LD —
английские. Именно их читает краулер.

### Слой 1. `t()` — видимый текст

```ts
t(ru, en, id?, th?)   // client/src/hooks/useLanguage.tsx
```

Добавление языка — это ещё один необязательный аргумент, ни один из 600+
существующих вызовов не трогается.

Инструмент: **`scripts/i18n/tcalls.py`** — разбор вызовов со счётом скобок и
кавычек (регулярка ломается о многострочные аргументы и апострофы внутри).

```bash
python3 scripts/i18n/tcalls.py list <файл>          # вызовы без 4-го аргумента, JSON
python3 scripts/i18n/tcalls.py inject <файл> <json> # вставить переводы по индексам
```

Найти все недопереведённые файлы разом:

```bash
for f in $(find client/src -name '*.tsx' -o -name '*.ts'); do
  n=$(python3 scripts/i18n/tcalls.py list "$f" | python3 -c 'import sys,json;print(len(json.load(sys.stdin)))')
  [ "$n" != "0" ] && echo "$n  $f"
done
```

Норма после перевода — не ноль, а три вызова: ссылка на мессенджер в
`Header.tsx` и `PricingSection.tsx` (там четвёртый аргумент не нужен, EN-фолбэк
и есть правильная ссылка) и строковая ветка в `FAQSection.tsx`.

### Слой 2. `document.title` и `meta[name="description"]`

Живут в `useEffect` каждой страницы (`client/src/pages/*.tsx`) ветками
`language === 'ru' ? … : language === 'id' ? … : …`. Провайдер их НЕ ставит:
эффект провайдера выполняется ПОСЛЕ эффектов детей и раньше молча затирал
все заголовки, включая пререндеренные снапшоты.

Найти забытые ветки:

```bash
grep -rn "language === 'id'" client/src --include=*.tsx | while IFS= read -r l; do
  f=${l%%:*}; n=$(echo "$l" | cut -d: -f2)
  sed -n "$n,$((n+4))p" "$f" | grep -q "'th'" || echo "MISSING → $l"
done
```

`syncOpenGraph()` копирует `og:*` и `twitter:*` из уже выставленных title и
description — отдельно переводить их не нужно.

### Слой 3. Схема (JSON-LD)

- `client/src/components/SEOSchema.tsx` — `pick(ru, en, id?, th?)`, тот же
  приём, что и `t()`. Плюс `inLanguage` и `locale` (`th-TH`).
- `client/src/components/AnswerLayout.tsx` — `Article`-схема страниц ответов.
- Отдельные `inLanguage` в `benchmark.tsx` и `answers-hire.tsx`.

Для GEO это не косметика: движки читают разметку в первую очередь.

### Слой 4. Конфиги данных

| Файл | Поля | Инструмент |
|---|---|---|
| `config/countries.ts` | `nameTh`, `inCountryTh`, `cityTh`, `platformsTh`, `socialProofTh`, `clientsTitleTh` + кейс-карточки | вручную |
| `config/faqs.ts` | `qTh`/`aTh` в 18 страновых вопросах + словари `IN_COUNTRY_TH`, `COUNTRY_NAME_TH` | вручную |
| `config/case-studies.ts` | `Th` у 78 групп полей + 133 инлайновые подписи в `heroStats`/`results`/`beforeAfter` | `scripts/i18n/cases_th.py` |

**`scripts/i18n/cases_th.py`** считает отступы и группы полей `Ru/En/Id`,
выдаёт английские значения списком и вставляет `Th` после `Id`-блока, правя
файл с конца, чтобы не сбить смещения:

```bash
python3 scripts/i18n/cases_th.py list client/src/config/case-studies.ts > en.json
python3 scripts/i18n/cases_th.py inject client/src/config/case-studies.ts th.json
```

Инлайновые подписи (`labelId`, `subId`, `metricId` в одну строку с объектом)
разборщик не видит — они правятся отдельным проходом по словарю
английских значений.

## Инфраструктура: что нужно тронуть при добавлении языка

1. `hooks/useLanguage.tsx` — тип `Language`, `LANGS`, определение по браузеру,
   `t()`, список `alternates` в `syncCanonicalAndAlternates`.
2. `scripts/prerender.mjs` — `const LANGS = [...]` (снапшоты в `lang-<код>/`).
3. `server/vite.ts` — регулярка допустимых кодов в отдаче снапшотов.
4. `client/public/sitemap.xml` — `hreflang` на каждый `<url>`.
5. `client/index.html` — `og:locale:alternate`.
6. Переключатель языков в `Header.tsx`.

## Проверка после деплоя

Смотреть глазами краулера, а не браузера:

```bash
curl -sA "GPTBot" "https://booster.delivery/th?lang=th" > /tmp/p.html
python3 -c "
import re
h=open('/tmp/p.html',encoding='utf-8').read()
print('символов языка:', sum(1 for c in h if '฀'<=c<='๿'))
print('title:', re.search(r'<title>(.*?)</title>',h,re.S).group(1))
print('desc :', re.search(r'name=\"description\" content=\"(.*?)\"',h,re.S).group(1)[:120])
"
```

Ориентир после полного перевода (09.09.2026): `/th` — 13 217 тайских
символов, `/benchmark` — 9 224, `/answers/in-house-manager-vs-agency` —
11 059, `/method` — 7 188.
