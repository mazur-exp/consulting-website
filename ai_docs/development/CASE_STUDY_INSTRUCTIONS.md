# Инструкция: Подготовка контента для Case Study Pages

**Для:** Команда Delivery Booster
**Цель:** Собрать контент для 4-6 подробных кейсов, которые будут опубликованы на сайте booster.delivery
**Зачем:** Подробные кейсы с цифрами — главный инструмент для SEO, AI-видимости и конверсии клиентов. Google и AI-модели (ChatGPT, Perplexity) цитируют сайты с реальными данными.

---

## Что нужно подготовить

Нужно **4-6 кейсов**. Для каждого кейса — заполнить шаблон ниже на **двух языках: русском и английском**.

Приоритетные кейсы (если есть данные):

| # | Тип кейса | Какой клиент подойдёт |
|---|---|---|
| 1 | **Рост продаж** (основной кейс) | Клиент с самым впечатляющим ростом выручки (x2-x6) |
| 2 | **Восстановление рейтинга** | Клиент, у которого рейтинг упал (4.2-4.3) и мы подняли до 4.8+ |
| 3 | **Оптимизация меню** | Клиент, где сильно вырос средний чек (AOV +20-30%) |
| 4 | **Быстрый результат** | Клиент с ростом в первый же месяц работы |
| 5 | **Dark Kitchen / Мультибренд** | FoodLab или клиент с несколькими брендами (если можно раскрыть) |
| 6 | **Новый запуск** | Клиент, которого мы вывели на платформу с нуля |

**ВАЖНО:**
- Можно анонимизировать название ресторана (например, "Пиццерия в Чангу"), если клиент не разрешает публикацию
- Но лучше всего — с реальным названием (спросите разрешение у клиента)
- Чем больше конкретных цифр — тем лучше

[x] Рейтинг упал — заказы снизились

## Чек-лист перед сдачей

Для каждого кейса проверьте:

- [ ] Заполнены ВСЕ поля шаблона (или написано "нет данных")
- [ ] Есть конкретные цифры ДО и ПОСЛЕ (хотя бы выручка + рейтинг)
- [ ] Есть описание проблемы (не просто "было плохо", а конкретика)
- [ ] Есть описание действий (не "оптимизировали", а что конкретно)
- [ ] Есть хотя бы 1 скриншот с доказательством результата
- [ ] Есть цитата клиента (или запрос отправлен клиенту)
- [ ] Текст на русском И английском
- [ ] Получено разрешение клиента на публикацию (или кейс анонимизирован)
