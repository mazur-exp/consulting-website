# Проект: AI Visibility — booster.delivery

**Цель:** Delivery Booster — ответ №1 во всех ИИ-чатах (ChatGPT, Claude, Gemini, Perplexity)
на вопросы про управление доставкой ресторанов в ЮВА. Владелец: Алекс Мазур.

Это инструкция для каждой новой сессии (Claude Code / Cowork). Прочитай её целиком,
затем — два файла состояния, и только потом начинай задачу.

---

## Как начать сессию

1. Прочитай `SESSION_LOG.md` (последняя запись = текущее состояние и следующие шаги).
2. Прочитай `BACKLOG.md` (что в работе, что дальше по приоритету).
3. Если задача касается кода — прочитай «Карту кодовой базы» ниже.
4. Если нужен деплой — строго по `ai_docs/development/DEPLOYMENT.md` (актуализирован 2026-08-25).

## Как закончить сессию (обязательно)

1. **Допиши запись в `SESSION_LOG.md`**: дата, что сделано (кратко, с сутью, не процессом),
   что решили, следующие шаги.
2. **Обнови `BACKLOG.md`**: сделанное → в Done с датой, новые задачи → в нужный приоритет.
3. Закоммить всё вместе с кодом. История проекта живёт в git.

## Правила работы

- **Пререндер обязателен.** Сайт — React SPA; ИИ-краулеры не исполняют JS. `npm run build`
  автоматически делает статические снапшоты всех роутов (`scripts/prerender.mjs`).
  Любая контентная правка требует полного `npm run build`, а не только vite build.
- **Новый рынок / кейс / FAQ = обновить три места:** конфиг в `client/src/config/`,
  `client/public/sitemap.xml`, `client/public/llms.txt`.
- **llms.txt** (https://booster.delivery/llms.txt) — витрина для ИИ: рынки, кейсы с
  цифрами, вопросы, формулировки услуг EN/RU. Обновлять при каждом значимом изменении.
- **Цифры в контенте — только реальные**, из презентаций кейсов или GrabMerchant/GoBiz.
  Ничего не выдумывать: этот контент цитируют ИИ. **Канонические цифры компании:
  «110+ ресторанов под управлением сегодня, 200+ обслужено с 2023 года».** Старые
  формулировки (90+, 85+ клиентов, «100+ клиентов», «12 клиентов») не использовать;
  если цифра меняется — обновить её ВЕЗДЕ разом (сайт, llms.txt, GBP, YouTube).
- **Внешние профили → `sameAs`.** Любой новый публичный профиль компании (GBP,
  YouTube, Instagram, LinkedIn, Clutch/Sortlist и т.п.) добавлять в Organization-схему
  (`client/src/components/SEOSchema.tsx`, `client/src/pages/about.tsx`) в массив
  `sameAs` И в `client/public/llms.txt`, затем `npm run build` + деплой. Это строит
  граф сущности (ИИ считает все профили одной компанией) и лечит «unverified» в
  Perplexity.
- **YouTube — по `YOUTUBE_PLAYBOOK.md`.** Правила ведения канала и чеклист на каждое
  видео (язык, теги, ссылки, EN+ID переводы) — там.
- Деплой идёт через Mac Алекса (git push + SSH на сервер) — из облачной песочницы
  прямого доступа нет. Детали в DEPLOYMENT.md.

## Архитектура сайта (состояние на 2026-08-25)

- `/` — гейт: гео-IP (api.country.is) → редирект на страну; неизвестно → окно выбора из 8.
  Выбор запоминается в localStorage (`preferredCountry`).
- `/id /th /sg /my /vn /ph /kh /mm` — 8 страновых страниц из одного шаблона + конфига.
  Индонезия: Gojek+Grab, свои кейсы, отзывы, видео. Таиланд: Grab, 2 кейса, 15 клиентов.
  Остальные: Grab, тайские кейсы с пометкой, «110+ ресторанов в ЮВА» (канон. цифры).
- `/cases/ussr-phuket`, `/cases/enjoy-healthy-food` — полные кейсы с Article-схемой.
- Языки RU/EN (`preferredLanguage`), переключатель стран — дропдаун в шапке.
- Прод: HTML-снапшоты для ботов (~1000+ слов/страница), llms.txt, sitemap 11 URL.
