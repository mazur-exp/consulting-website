━━━ ЖЕЛЕЗНЫЕ ПРАВИЛА ━━━
- Сайт — React SPA, ИИ-краулеры не исполняют JS. Любая контентная правка
  требует полного `npm run build` (пререндер 24 роутов × 2 языка = 48 снапшотов).
  Проверка: curl -sA "GPTBot" https://booster.delivery/th | wc -w → 1000+.
- Новый рынок / кейс / FAQ = обновить ТРИ места: конфиг, sitemap.xml, llms.txt.
  Новая СТРАНИЦА — шесть: роут в App.tsx, prerender.mjs, sitemap.xml, llms.txt,
  реестр AnswersIndex.tsx и живая <a href> с гейта или из FAQ-секции.
- Три языка: RU, EN, Bahasa Indonesia. Перевод — t(ru, en, id?), третий аргумент
  необязательный. Индонезийская версия для ботов существует только как отдельные
  снапшоты в lang-id/, которые сервер отдаёт на ?lang=id.
- Имя основателя латиницей — строго Aleksei Mazur. Не Alexey, не Alexei, не Aleksey.
  Разнобой ломает граф сущности: для ИИ это разные люди.
- Перед добавлением страницы прочитай раздел «Грабли» в README: три бага этого
  проекта (title, og:url, коллизия снапшота с папкой) не видны ни в логах, ни глазом.
- Цифры в контенте — только реальные, из презентаций кейсов или
  GrabMerchant/GoBiz. Этот контент цитируют ИИ — не выдумывать ничего.
- Деплой строго по ai_docs/development/DEPLOYMENT.md: git push → ssh на сервер,
  прод живёт в /root/consulting-website (systemd consulting-website).
  /var/www и pm2 — старьё, НЕ использовать.
- В названии Google Business Profile — никаких ключевиков (риск бана),
  ключевики только в описании/услугах/отзывах.
